# 0.1.2版本验证范围

使用虚构数据在隔离目录执行，不读取原使用者的账本或修改其现用自动化。

| 范围 | 本次检查 |
|---|---|
| 每日回顾脚本 | 14项测试：新增/改名/重名/排序及详情、完整与局部完成、保守日期、错误输入、导出链接、公式注入防护、失败回滚和主账保护 |
| 桌面数据/配置 | 81项检查：规范主账与独立JSON、通用稳定ID、详情合并、增删改名、日期与状态、旧今日选择、错误保留和路径时区 |
| 安装/打包 | 安装和插件入口检查保留；8项打包测试覆盖源码允许清单、合成示例、隐藏文件、运行数据、符号链接和失败不覆盖成品 |
| 独立界面 | 隔离合成数据17项检查通过，包括详情展开、刷新保留展开与滚动、主账创建和删除、错误保留；未开启开机自启 |
| 技能格式 | 5个技能入口通过Skill Creator自带格式校验，验证依赖仅用于开发，不加入运行依赖 |
| 发布隐私 | 17项自动门禁检查中16项通过、1项Windows真实文件符号链接因权限跳过，对应模拟与ZIP符号链接检查通过；审查工作树、暂存区、历史文件及路径和最终ZIP，并人工复核内容。私人词表保存在仓库外，报告不回显命中原文 |

这份记录描述检查范围，不能代替每位使用者的实际鼠标、屏幕缩放、多屏和图标布局试用。插件目录的真实安装与定时任务注册依赖接收者自己的客户端和账号，打包测试没有把它们视为已启用。

自动扫描覆盖已知格式和提供的私密词，人工复核用于检查真实任务、个人线索与源码选择。通过检查不等于证明所有自然语言都没有隐私。发布包的最终校验值随版本的`SHA256SUMS.txt`提供；发布前流程见[发布隐私检查](RELEASE-PRIVACY.md)。
