# 每日回顾与任务总账

先使用用户明确指定的 `workflow.config.json`。若未指定，读取本技能目录中安装器生成的 `installation.json`，使用其中的 `configPath`；没有安装元数据时再检查当前工作目录。仍没有时使用 [初始总账](assets/ledger-template.md) 建立一个独立工作目录，或询问保存位置。已有账本优先，不覆盖用户的目标、历史或配置。

执行日常回顾时读取 [回顾协议](references/review-protocol.md)。以配置中的 Markdown（标记文本）总账为唯一事实来源，按发生日期追加历史；任务表用于当前状态。可访问的聊天和用户允许的资料是补录证据，缺失记录不表示没有工作。

区分讨论、建议、计划、用户完成声明与已验证成果。用户明确说已完成可销账，注明依据，不额外要求每项证明；没有运行日志的科研计划不计为实验成果。保留来源聊天标识或用户给出的出处，但不主动扩大资料访问范围。

每天先回顾昨天，再结合固定日程、真实截止和长期目标安排今日重点。建议一个核心成果及少量辅助事项，注明建议性质并预留机动；未完成事项应判断延期、阻塞、继续或取消。科研、课程、工具、个人事务分别记录，科研周报只提取相关成果与支撑，不用聊天量、任务量或推测工时评价能力。

更新总账后运行本技能携带的脚本，用技能文件所在位置解析绝对路径，不假设当前工作目录就是技能目录：

```text
python /path/to/daily-review/scripts/refresh.py --config /path/to/workflow.config.json
```

脚本只刷新派生视图，不修改总账。默认生成 `tasks.json`、带定位链接的网页和一份 `任务总览.xlsx`；不需要第三方 Python 包。若文件被占用，保留旧视图并说明刷新失败，不另建“更新版”。配置与格式见 [数据接口](references/data-format.md)。

定时任务的提示词可用 [提示词模板](assets/automation-prompt.md)。安装技能本身不会创建日程；只有用户要求定时运行时，查找当前环境支持的原生自动化工具创建或更新任务，保留用户已有时间、时区和通知偏好。找不到注册工具时提供可复制提示词并明确尚未注册，禁止手写内部自动化配置冒充已启用。

完成后简述新增成果、今天重点、近期截止和确需补充的信息。受阻时说明覆盖缺口及原有记录是否保留，不宣称全量核查成功。
