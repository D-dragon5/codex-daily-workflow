更新长期目标、本周目标、今日重点、当前任务和历史。今日安排尊重固定日程与真实截止，建议一项核心成果和少量辅助事项，预留机动，检查延期或阻塞原因。科研、课程、工具和个人事务分别记录；每周滚动积累科研周报草稿，不将课程或计划写成科研成果，不代发给他人。不要以聊天量、任务量或臆测投入时长评价表现。
