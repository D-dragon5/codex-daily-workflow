# 迁移与验证

## 三种入口

- **完整使用**：下载ZIP，运行`install.cmd`，再在自己的Codex里调用`$setup-daily-workflow`完成定时任务注册。
- **只要回顾**：复制`modules/daily-review/skills/daily-review/`到自己的技能目录。模板和脚本均包含在技能内。
- **只要面板**：复制`modules/desktop-board/`并运行`build.ps1`，编辑其合成任务文件，或指定自己的配置。

安装器可以指定独立的`InstallRoot`、`DataDir`和`SkillRoot`。代码与数据分开，升级时不覆盖主账本。自己的真实文件无须复制到本仓库；尤其不要提交`data/`、`installation.json`或显示设置。

## 定时任务的可移植边界

本仓库包含提示词与设置技能，不包含可跨账号复用的已注册定时任务身份。使用者需在自己的客户端创建任务；本机工具可用时设置技能直接调用，否则提供可复制请求并标明待注册。定时任务已安装、已启用、已执行是三种独立状态。

默认使用本机时区，时间05:30可修改。对于本地文件，电脑与客户端必须在任务运行时可用。[官方说明](https://learn.chatgpt.com/docs/automations?surface=app)

不复制别人的聊天ID，不直接写应用内部自动化文件，不修改已有同用途任务前先确认它的用途。已有任务应更新，避免同一日重复提醒。

## 本机验证顺序

1. 在隔离目录安装，加`-NoShortcut`，不使用`-StartWidget`。
2. 检查示例总账、任务JSON、Excel和网页的一致性，以及重复安装保留用户修改。
3. 运行桌面模块数据测试；需要可见界面时再对独立示例配置运行`--smoke-test`。
4. 手动试用拖动、锁定、矩形滚轮、靠右和桌面图标避让。程序命中或路由检查不足以替代真实鼠标手感验收。
5. 在自己的Codex手动做一次回顾，再注册自动任务并检查第一轮结果。

## 更新与移除

更新前退出本工作流的日程板副本，再对原安装位置重新运行安装器。配置、主账和手动任务保留；已有同名但不属于本项目的技能拒绝覆盖。

移除时先在客户端停用/删除你注册的定时任务，关闭日程板，在程序内关闭曾启用的开机启动。然后按安装元数据核对并移除本项目的应用目录、技能和快捷方式；主账与数据目录可独立保留。仓库没有静默递归删除用户目录的卸载器。

## 已知限制

- 桌面面板仅Windows，图标读取依赖系统公开无障碍几何，读取受限时会明确失败。
- 每周课程重复暂不表达学期周次或单双周，请按实际安排增删。
- 没有访问工具的聊天、线下工作与未同步文件须由本人补记，不能从缺失记录推断没有工作。
- 公开版为脱敏整理后的0.1版本。现有功能来自持续试用优化，尚未覆盖所有Windows缩放、多屏和桌面组合设置。
