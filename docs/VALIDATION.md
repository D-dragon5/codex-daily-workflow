# 0.1版本验证范围

使用虚构数据在隔离目录执行，不读取原使用者的账本或修改其现用自动化。

| 范围 | 本次检查 |
|---|---|
| 每日回顾脚本 | 9项测试：任务解析、状态/日期、重复ID和非法日期、HTML转义、表格公式注入防护、日期/链接导出、失败回滚、不覆盖总账 |
| 桌面数据/配置 | 19项检查：相对路径、时区、任务稳定ID、空列表、错误输入、今日选择和建议逻辑 |
| 安装/打包 | 6项测试：完整安装、重复安装保留记录、外来目录/技能保护、已有手工任务保护、插件源路径、合成示例保留及运行文件排除 |
| 独立界面 | 虚构3项任务的冒烟运行通过，测试偏好与正式配置分开，不开启开机自启 |
| 技能格式 | 5个技能入口通过Skill Creator自带格式校验，验证依赖仅用于开发，不加入运行依赖 |
| 发布隐私 | 文本规则扫描和人工目录检查；压缩包不含真实任务、聊天身份、机器路径或运行偏好 |

这份记录描述检查范围，不能代替每位使用者的实际鼠标、屏幕缩放、多屏和图标布局试用。插件目录的真实安装与定时任务注册依赖接收者自己的客户端和账号，打包测试没有把它们视为已启用。
